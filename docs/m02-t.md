# M02-T temporal Geometry

M02-T is a single fixed temporal-dependency extension of M02-base. It keeps
the frozen 21-dimensional L1/L2 Geometry representation and appends 64
features computed from a one-second as-of grid over the preceding 60 seconds.
The windows are fixed at 5/15/30/60 seconds; no outer-aware selection or LB142
reference is used.

The full feature artifact is generated locally with
`build-geometry-temporal`, then evaluated by the same nested residual
CatBoost/alpha protocol as M01-A and M02-base. It remains ignored and is not a
competition submission.

After this experiment, both static Geometry and its fixed temporal dependency
extension are considered insufficient for the candidate gate. No additional
M02 windows, lead-lag variants, or test predictions are started automatically.
The next independent family is M03 depth-2 Path Signature.
