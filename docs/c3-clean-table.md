# C3 Clean Table v2

C3 reproduces the legacy v5 table representation under the registered nested
temporal protocol. It does not change the historical feature or model recipe:

- 90 official features, with exactly eight R2 directional replacements;
- 22 legacy microstructure features;
- LightGBM, CatBoost, and a three-seed PyTorch MLP;
- fixed component blend `0.2 LGBM + 0.5 CatBoost + 0.3 MLP`.

For every outer, component stopping points are selected on the corresponding
inner tune months using uncentered cosine. Models and the MLP scaler are then
reinitialized and refitted on registered history before outer prediction. The
outer target never selects a feature, transform, iteration, or blend weight.

Run one fold locally:

```powershell
$env:MSCAP_DATA_ROOT = "D:\mscapital-forecasting\data"
python -m mscapital clean-table `
  --config configs/clean-table-v2.json `
  --outer PSEUDO
```

The optional private Kaggle data bundle and four self-contained kernels are
generated by `scripts/build_kaggle_c3.py`. `--push` publishes private training
kernels; it does not create a competition submission.

Predictions and model artifacts stay ignored. Only code, configuration, and a
sanitized aggregate result report may be published.
