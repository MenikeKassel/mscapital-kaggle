## 0. 摘要 (TL;DR)

**成绩阶梯**: 0.122 (表格融合) → 0.123 (R2 归一化) → 0.125 (微观特征) → **0.135 (RealMLP 事件动力学, 最大单步 +0.010)** → **0.142 (外部正交融合)**。

**三次有效台阶 = 三次"换信息源/换表示"**, 不是模型调参:
1. 绝对量 → 无量纲相对量 (R2 归一化, 延长 alpha 寿命)
2. 官方 90 特征 → 152 事件动力学特征 × RealMLP 架构 (特征×架构组合效应)
3. 自研 → 公开最强推理包预测 (corr 0.82 的独立 18% 信息)

**最重要的科学发现**:
- **MSE 失败机制**: target = sign·|y| 且 E[sign|x]≈0 → MSE 最优解≈0; cosine 兑现弱方向信号。方向信息弱 (AUC 0.56), **幅度信息是富矿** (corr 0.43-0.47, 大波动识别 AUC 0.78) — 与外部评审的猜想完全相反。
- **market 600s 序列 = 第二套正交 alpha**: 聚合特征无信号 (34 特征 −0.0002), 序列 + cosine 有信号 (corr(y)=+0.086, frozen Δ+0.0009) — 信息以序列形式存在, 不在低维统计量中。
- **信息结构五条实锤** (P5-02I): 时序必要 / 无时间箭头 / 短程 ≤10 步 (30s) / 跨通道同步是核心 / 非线性相位形态。

**最惨痛的教训**:
- v6 (TCN): 本地 PSEUDO +0.0044 → 真实 LB **0.082** (灾难)。序列模型在 38 个月 OOD 测试期严重退化, test 上 corr(tab, tcn)=0.03。
- 残差路线 5 连杀: P4-06A / P5-02I resid probe / P5-03 / P6-01 / P6R-00 — "残差可解释性 ≠ 残差可预测增量"。

## 1. 比赛与数据 (原理基础)

### 1.1 赛制 (官方核验, 2026-08-14)

| 项 | 值 |
|---|---|
| 任务 | 预测未来价格变化, 指标 = 未中心化 cosine(prediction, target) |
| 数据 | 真实市场数据简化抽样 (官方原话: "simplified sample"), 三路时序: market / order / transaction |
| 规则 | 个人赛 (团队=1), 每日 ≤5 提交, 最终选 ≤2 份 Final, Public=49% 测试 / Private=51% |
| 奖励 | Kudos 无现金奖; 前十 (主办方不参与排名) 上海线下交流 + ≤5000 RMB 报销 |
| 时间 | 2026-07-07 开放, 2026-10-10 截止 |

### 1.2 数据生成结构 (取证, scripts/zz_forensics_datagen.py)

```
真实市场 LOB 连续流 (单一主标的, 价格匿名化到 ~1.0)
  → 按月切片 (train 0-70 共 71 月, 每月 ~17.4k 样本均匀抽样; test 71-108 共 38 月 OOD)
  → 每月随机抽 10 分钟窗口 (预测时刻 = 窗口末端)
  → 每窗口输出 4 层:
     label        = 窗口后的未来收益 (口径刻意未公开)
     market       = 全 600s × 3s bar: L1/L2 报价 + bar 内成交聚合 (压缩层, ~200 行/样本)
     order/tx     = 最后 60s 原始订单/成交事件流 (明细层, 10× 截断省体积)
```

关键结构事实:
- **market.feather 是全历史信息的压缩层**; order/tx 只是最后 60s 的细节放大。
- 匿名化指纹: 价格按样本归一化到 1.0 (打破真实 tick 网格); 0.5 价簇 (~0.76%) 疑似第二标的; 100 股手数 (97.9%) 真实 lot size; 无日期/代码/交易所字段。
- 样本间无序列关系 (相邻 sample_id 边界跳变 ratio ≈ 1.0) → 跨样本序列重建不可行。
- target: mean −1.2e-5, std 2.6e-3, 正占比 44.9% (略负)。|target| 随波动率单调递增 2.6× → 未归一化收益类量。

### 1.3 三路数据的信息角色 (事后总结)

| 数据 | 覆盖 | 已挖掘 | 状态 |
|---|---|---|---|
| order/tx 60s | 原始事件流 | 152 事件动力学特征 (v7 主力) + 22 微观特征 (v5) + 秒级聚合序列 (TCN) | **已吃干** (3 条表示路线全负) |
| market 600s | 3s bar 序列 | 34 聚合特征 (无信号) + 序列建模 (P5-01/02I 实证) | **唯一未吃干的信息层** |
| label | 未来收益 | 月漂移后处理 (死), target 逆向 (5 路取证, 官方不公开) | 基本关闭 |

## 3. 验证体系建立 (P0 阶段, 2026-08-11) — 探索的地基

### 3.1 CV 协议: 切分敏感性 (A1)

**方法**: 同特征同参数 × 4 种按月切分。
**效果**: CV1 (m0-50/m51-70) 0.1302 / CV2 0.1338 / CV3 0.1352 / CV4 0.1418 — **验证期越近越乐观**。
**原理**: 金融数据分布漂移, 近期验证区间与 test 期分布更接近, 且验证样本更少。
**结论**: CV1 最诚实 (与 LB 0.117 官方基线对齐), 冻结为主评估协议。后续所有实验在此基础上展开。

### 3.2 Temporal Matrix: 模型选择的可靠性 (P0-1)

**方法**: 7 个时序 fold (T1-T4/H1/H2/PSEUDO38) × 5 模型 (LGBM/XGB/CatBoost/MLP/blend)。
**效果**: MLP CV1 第一 (0.1337) 但 7/7 temporal folds 垫底 (mean 0.1187); CatBoost 最稳 (mean 0.1264); blend 全 fold 全胜 (+0.003)。
**失败原因 (评估协议 bug)**: 原矩阵用 **last-epoch** 评估 MLP, 树模型无此问题。P0.5-B 修复为 best-state 后 MLP +0.006 → "MLP 假冠军" 修正为 "评估协议高估其劣势 + MLP 确实弱于 CatBoost"。
**教训**: NN 评估必须 best-state tracking, 否则跨时间结论可能是假象。

### 3.3 Adversarial Validation: 漂移归因 (P0-2)

**方法**: 训练 LightGBM 区分 train/test, AUC + 特征重要性。
**效果**: train 内早 vs 晚 AUC 0.733 / 近期 vs test 0.777 / 全量 vs test 0.766 — 漂移确认且持续演化。
**关键发现**: **预测主力特征 = 漂移主力** (m_sp_mean/m_depth_mean/m_rv 盘口价差深度波动), 特征组漂移: 盘口 45% > 订单 22% > 窗口 19%。
**原理**: 这给出了 CV-LB 差 0.017 的机制解释 — 模型学到的是 m51-70 regime 的 alpha, 而 test 期 (71-108) 是另一 regime。

### 3.4 Drift Intervention: R2 归一化 (P0.5-C, 科研验证链完整闭环)

**方法**: 三臂对照 — R0 (原 90 特征) / R1 (删 top10 漂移特征) / R2 (绝对→相对替换: spread/mid、depth/vol、rv/std 等纯自身比率)。
**效果**: R2 **4/4 folds 全正** (mean +0.0023), 远期 fold 提升最大; v4 提交 LB 0.122→**0.123** 兑现。
**原理**: 相对表示不依赖跨样本统计量, 对市场状态演化 (价差/深度/波动系统性漂移) 不敏感 → "归一化延长 alpha 寿命"。**这是漂移类比赛最有效的单一杠杆**。

## 4. 特征工程探索 (A/B/C/D/E + P1 系列)

### 4.1 特征数量甜点位 (A2/B1/B2/C1)

- 17 → 90 特征: CV 0.0969 → 0.1302 (+0.0333), 增量特征 (窗口/EWM/交叉) 贡献绝大部分预测力。
- **90 特征 = 稳定甜点位**: 增到 109 (C1) 略降; 社区 >90 特征 CV 0.1409 但 LB 0.116 (N002) — 过拟合漂移。
- 特征组消融 (B1): 窗口统计是绝对主力 (−0.0102), EWM/成交基础可删 (移除无损失)。

### 4.2 时间衰减加权 (E1): 失败

**方法**: 线性 2x/3x、指数温和/强加权近期样本。
**效果**: 全部无效或有害 (0.1302 → 0.1250 最差)。
**失败原因**: 近期加权不能桥接漂移; **旧月份数据量价值 > 近期相似度**。且漂移是市场状态演化, 不是简单时间距离 (P0-2 佐证)。

### 4.3 22 个微观结构 primitive (P1-1): 成功

**方法**: 无量纲相对形式 (add/cancel imbalance、归一化 OFI、事件到达率、burstiness、局部大单、成交强度、fast-slow flow、microprice gap、相对价差、L2 深度不平衡)。
**效果**: PSEUDO 0.1313 → 0.1349 (+0.0036, 迄今最大单步超 R2 两倍), v5 LB 0.123→**0.125**。
**原理**: 业务意义明确的相对量特征, 与 R2 归一化同构 (对抗漂移) 且补充 order/tx 事件结构信息。
**双轴筛选 (P1-1b)**: Alpha 轴 mean +0.0022 但 ΔAUC +0.0168 ⚠️ — 部分强度类特征也携带漂移。
**第二轮相对化 (N006) 失败**: 到达率/强度类特征再相对化 PSEUDO −0.0012 — 第一轮已是最优, 特征工程到顶。

## 5. 序列模型路线 (P1-2 TCN / N003 Transformer) — 最惨痛的失败

### 5.1 方法

双塔 TCN: FAST (order+tx 60s 秒级聚合 16 通道) + SLOW (market 60 bar 8 通道), dilation 1/2/4/8 小 TCN, 远程 Kaggle GPU + 本地混合训练。Sequence-only 模型, PSEUDO fold 验证。

### 5.2 效果 (验证期 "成功")

- sequence-only cos 0.0627~0.0738 (远低于表格 0.13, 但 **corr(seq, tabular)=0.28-0.40 极度互补**)。
- 3-fold 融合验证全正: T3 +0.0035 / T4 +0.0023 / PSEUDO +0.0044 → v6 提交 (7% 权重)。
- **PSEUDO 0.1379 看似能冲 0.13, 真实 LB = 0.082** — 比赛最大单次回撤 (−0.043)。

### 5.3 失败原因 (事后完整归因)

1. **test 分布外 (OOD) 退化**: test 上 corr(tab, tcn) = **0.03** (验证期 0.30-0.40) — 序列模型学到的模式在 38 个月后的 test 期失效。PSEUDO fold (m33-70) 与 test (m71-108) 的分布距离, 对序列模型是致命的。
2. **尺度迁移**: v6 test/valid std 异常 (验证时已有预警信号但被 PSEUDO 增益掩盖)。
3. **验证协议盲区**: 表格模型 PSEUDO 校准可靠 (0.1349→0.125), 序列模型完全不可信 — 不同模型族的验证可靠性不同。
4. 工程坑一串 (远程 3 次 ERROR: polars streaming dtype panic / P100 与预装 torch 不兼容 / 内存), 消耗了大量时间。

### 5.4 形成的规则 (制度)

- 新模型必须同时过: PSEUDO 增益 + **test 预测相关结构不坍缩** (corr 门禁) + **尺度门禁** (std_test/std_valid) + 分布门禁。
- TCN/Transformer 路线冻结。

## 6. 事件动力学 × RealMLP (v7) — 最大自研成功

### 6.1 方法

1. **复刻公开最强解的特征源**: 从 yunsuxiaozi 的 RealMLP notebook 逆向出 152 个事件动力学特征 (diff/shift、时间指数加权、事件顺序、间隔统计 — 与自家窗口统计完全不同的信息源)。
2. **复刻模型**: RealMLP_RQ (arXiv 2407.04491), n_ens=16, 作者训练配置一字不改。
3. **融合**: v5 表格 × RealMLP 0.8/0.2 (权重网格实测 0.20 是甜点位, 0.25 反降)。

### 6.2 效果

- RealMLP 单模型 PSEUDO 0.1386 > 自家表格 0.1349。
- v7 = 0.1397 PSEUDO → **LB 0.135** (+0.010 单步, 超过公开 RealMLP 单模型 0.134)。
- corr(table, RealMLP): valid 0.866 / test 0.826 — 相关结构稳定, 融合增益真实。

### 6.3 原理与归因 (关键)

**提升来自特征×架构组合效应, 不是特征本身** (归因实验): 152 特征 × CatBoost/LGBM 的 PSEUDO 只有 0.127 (低于官方特征 × CatBoost 0.130), 而 152 × RealMLP = 0.134+。→ 复制别人的分数必须复制完整管线。

**Regime B 校准**: v7 gap = LB − PSEUDO = **0.0047**, 明显小于表格模型的 0.008-0.010 — 新表示在 test 上转化更好, 但只有 1 个定标点, 不能外推为通用公式。

## 7. 外部正交融合 (v8a/v8b) — 排名跳升

### 7.1 方法

LB142 公开推理包 (作者开源, 66.9MB): MultiStream + RealMLP v9/v10, 5 成员 ens5 ⊕ v10, 公式 `0.6·ens5 + 0.4·unit(v10)`。直接下载成品预测文件融合 (免训练)。

### 7.2 效果

- corr(v7, ref) = **0.82** → 独立信息 ~18%。
- 权重网格: 0.3 → LB 0.139; **0.5 → LB 0.142** (#30/107), 追平公开最强。
- 与"复刻单模型"不同, 融合**成品预测**时 0.5/0.5 是常见甜点位 (作者预测已是多模型融合体)。

### 7.3 纪律

- Regime C (外部预测): 无共同 validation → 不进入本地校准公式, 只当 ensemble probe。
- **不连续扫 Public LB 权重** (0.3→0.5 两个点即停; 拿 Public LB 当验证集 = Private 风险上升)。

## 8. 残差/条件化研究 (Protocol-v2 C/E/M/P3/P6R) — 大面积失败的科学

### 8.1 Protocol-v2 基建 (C 系列)

- C3 Clean Table: 四折可信 outer, PSEUDO 0.1351, 与 legacy v5 一致 (corr 0.9922) — 历史结论真实。
- C4 Clean Baseline v2 frozen: 生产规则 `0.63×RMS(RealMLP) + 0.37×RMS(Clean Table)`, 四折 0.1426/0.1418/0.1435/0.1569。
- canonical residual OOF (21-70, 885,936 行, 严格 source_train_end < month) 成为所有残差研究的地基。

### 8.2 E 系列: 状态条件化

| 实验 | 方法 | 效果 | 判定 |
|---|---|---|---|
| E01 ReVol-lite | 37 个波动率/状态特征, 残差 CatBoost | 四折全正, PSEUDO +0.00110 | **gate False** (差 0.0015 门槛 27%) |
| E03 稳定性审计 | 月级 bootstrap | positive-month 0.842, CI 下界 >0 | 附加 gate 通过, 不覆盖基础 gate |

**关键矛盾**: E02 窗口内 (同月训练+预测) 残差可解释性 0.013, 但 E01 严格 OOF 只变现 +0.0011 → **"残差可解释性 ≠ 残差可预测增量"** 的第一条证据。

### 8.4 P3: 第二代表示 (让模型自己学)

| 实验 | 方法 | 效果 | 失败原因 |
|---|---|---|---|
| P3-01 SAE | 32d 监督自编码器 latent + 152 | PSEUDO **−0.00076** | latent 与 152 手工特征信息重叠 (SAE 从同一批特征学; 冠军 AE 是在**匿名**特征上学) |
| P3-02 状态条件化 | 37 ReVol + 24 事件流拼接 | +0.00095 (四折全正) | 门禁差 0.0005; 拼接稀释纯状态信号 |
| P3-03 TinyLOBERT | 掩码预训练 latent | **预注册门禁终止** | corr(latent, 152) = 0.86~0.98 >> 0.70 — 网格表示被窗口统计完全覆盖 |
| P3-04 2.5D 网格 | 60×6 秒级聚合 + 价格直方图投影 | +0.0000 | 聚合丢事件顺序 (与 TCN 教训同源) |
| P3-05 NHP 强度 | 事件强度诊断 | 门禁通过但 \|r\|≤0.01 | 强度-残差线性关系几乎为零 |

**整体判断**: "第二代表示"在当前数据形态下全部被 152 特征 + 窗口聚合覆盖 — **信息已经不在低维表示里, 在序列本身**。

### 8.5 P6R: 检索条件化残差 (2026-08-14)

**方法**: E02 11 context 特征为状态表示 → 严格时序 KNN (month < query) → 检索残差均值 r̂ → y_hat = RMS(y0) + α·RMS(r̂)。预注册 8 候选 (K{64..512} × {euclidean,cosine}), 零追加。

**效果**: **32/32 候选×折 Δc4 > 0** (无一转负), 最大 PSEUDO Δ = +0.000588 (cosine_K512) = 门禁的 39%; corr(r̂,r) = +0.004~+0.010; corr(r̂,y0)≈0 (正交); α 几乎全卡网格下界 0.05。

**失败原因 (failure analysis)**:
- 检索机制本身健康 (邻居月份熵 3.24/3.91 接近最大, 覆盖 27/50 月) — 问题在"相似状态的残差均值本身预测力弱"。
- E02 的窗口内信号 (0.013) 在跨月迁移 + 检索均值后被稀释到 corr ~0.005-0.010 — 可迁移部分 < 1%。
- **KILL retrieval route**: 这是"残差不可预测"链的第 5 个独立确认 (P4-06A / P5-02I probe / P5-03 / P6-01 / P6R-00)。

## 9. 隐藏信息调查 (P4 系列) — 输在哪里的侦察

### 9.1 核心问题: 0.135/0.142 vs 前排 0.155-0.159 的差距来自哪里?

**H1-H5 假设与判定** (证据加权):

| 假设 | 内容 | 概率 | 判定 |
|---|---|---|---|
| H4 | 600s 盘口快照流 + 未知 factors 表 (我们从未建模) | 45% | **主嫌疑** (后被 P5-01/02I 证实方向正确) |
| H3 | target 含月度市场漂移分量 (未归一化收益) | 30% | 取证支持 (月均值漂移 16.5se) 但 P4-05 证伪可利用性 |
| H5 null | 更强模型 + 训练技巧 | 15% | 部分 (LB142 三流网格 + cosine loss + online BN) |
| H1+H2 | 伪资产 / 跨样本序列 | 10% | 0.5 价簇存在但占比 0.76%, 影响有限 |

### 9.2 LB142 分歧取证 (p4_lb142_forensics)

**方法**: d = unit(ref) − unit(v7), 对比高 |d| 与低 |d| 样本画像。
**发现**: 分歧集中在**高活动 (订单数 2.6×)、高波动 (2.3×)、强自相关 (3×)、数据完整**的样本 — LB142 在信息量大的样本上掌握了额外信息; 分歧随活动度单调 (系统性方向偏差, 非噪声)。
**反证**: 34 个 600s 聚合特征 PSEUDO −0.0002 无信号 → 要么聚合丢序列信息 (后证实: 是!), 要么信息来自 factors/训练技巧。

### 9.3 P4-05 月漂移可预测性: 决定性负结果

**方法**: 8 方法 × 4 outer (滚动月均值/固定效应/回归等) 预测未来月均值。
**结果**: 全 Δ ≤ 1e-6, ACF 全 |r| < 0.25。
**结论**: **存在漂移 ≠ 可利用漂移**。月均值后处理关闭 — H3 的市场分量不可变现。

### 9.4 P4-06A 证据链: 链条断裂

600s 聚合状态 → LB142 分歧 ✓ (R² 18.4× null, 解释模型行为) 但 → y−v7 残差 ✗ (+0.0000)。
**结论**: 长上下文是"模型行为解释变量", 不是"target 缺失信息源"。

### 9.5 P4-08A / 4.14: cosine loss 收口

- 受控消融 (同输入/同架构/同切分): cosine 头 +0.00703 vs MSE +0.0000 — cosine 看起来巨大。
- **4.14 严格复刻**: 只 +0.001, 两次 Public 0.135 自洽 → **cosine 是真实但小的互补**。
- 事故根因: lambda_cos=0.01 名义混合实际 99% MSE — 判定"用了 cosine"前必须审计 loss 权重。

## 10. Market 600s 序列深挖 (P5-01 / P5-02I / D1-D3) — 当前的主战场

### 10.1 P5-01: 信息存在性审判

**方法**: market-only 600s 序列 (200 步 × 18 通道, 均匀 3s 网格), 小残差 Conv1D, **双臂对照唯一变量 = loss** (MSE vs cosine), 21-40 训练 / 41-50 选 α / 51-70 冻结。

**效果**:

| 指标 | MSE 臂 | Cosine 臂 |
|---|---|---|
| corr(market, y) | **−0.0013** (无信号) | **+0.086** (真实信号) |
| corr(market, v7) | −0.007 | +0.492 (独立方向) |
| FROZEN 51-70 Δ | −0.0002 | **+0.0009** (17/20 月正) |
| 活动度分层 | 全负 | lo +0.0021 / hi +0.0006 |

**Gate 判定**: 信息存在 ✓ / 独立性 ✓ (corr 0.49) / 正式门禁 Δ≥+0.0015 ✗ (+0.0009)。

**核心原理: loss × 信息源交互** — 弱信号新源必须先测方向型 objective。MSE 无信号 ≠ 信息不存在。这同时解释了 LB142 为什么 market 网格 + cosine 一起用。

**高活动假设被反驳**: 预期高活动增益大, 实际**低活动最强** — market 序列捕捉的不是 LB142 分歧画像那类高活动信息, 而是另一类 (低活动/流动性弱期的定价信息)。

### 10.2 P5-02I: 信息定位 (8 臂 surrogate + 5 probes)

**方法**: 对 market 序列做 8 种破坏 (shuffle/reverse/block10/20/50/desync/phase), 每臂重训, 相对损失 R = (M0−Mk)/M0。

| 臂 | 破坏什么 | corr(y) | R(corr) | frozen Δ | R(Δ) | 判读 |
|---|---|---|---|---|---|---|
| M0 raw | 基线 | +0.0861 | 0 | +0.000926 | 0 | 基线 |
| M1 shuffle | 全部时序 | +0.0231 | 0.73 | +0.000155 | 0.83 | **时序必要** |
| M2 reverse | 时间方向 | +0.0852 | **0.01** | +0.000929 | ~0 | **无时间箭头** |
| M3-5 block10/20/50 | 长程关系 | ~0.026 | 0.69-0.70 | ~0.0002 | 0.69-0.81 | **信息尺度 ≤10 步 (30s)** |
| M6 desync | 跨通道同步 | +0.0197 | 0.77 | +0.000057 | 0.94 | **跨通道同步是核心** |
| M7 phase | 相位形态 | +0.0038 | 0.96 | −0.000256 | 1.28 | **非线性相位形态** |

**五条实锤**: alpha = **短时窗 (≤30s) 内跨通道同步的、时间反演对称的非线性事件形态**。

**Probes (target 结构诊断)**:

| probe | 指标 | 值 | 判读 |
|---|---|---|---|
| sign(y) | AUC | 0.56 | 方向信息微弱 |
| rank(y) | corr | 0.089 | 方向信息全在 rank 里 |
| \|y\| | corr | **0.43-0.47** | **幅度信息巨大** |
| extreme(\|y\|>p90) | AUC | **0.78** | 大波动识别能力极强 |
| y−β·v7 方向 | AUC | 0.51 | **残差方向无信息** (P5-03 预判死) |

**⚠️ GPT1 猜想反转**: 评审预测 "sign 大/magnitude 小", 实测**完全相反** — 幅度是富矿, 方向是瓶颈。这给出 MSE 失败 / cosine 成功的精确机制: y = sign·|y|, E[sign|x]≈0 → MSE 最优解≈0; cosine 兑现弱方向。

**架构推论**: 短程 ≤10 步 → 感受野 20-30 步足够 (淘汰 Transformer 长注意力/TLOB/长 TCN); 跨通道同步 → channel-mixing 第一优先 (MLPLOB 首层逐时间步 FC 天然匹配); 无时间箭头 → 方向性 RNN/SSM 无优势; 非线性相位 → 学到的表示优先于手工特征。

### 10.3 D1-D3 幅度诊断: 机制闭合

| 诊断 | 结果 | 含义 |
|---|---|---|
| corr(\|v7\|, \|y\|) | +0.156 | v7 幅度校准弱 (market 幅度预测 0.43 是其 3 倍) |
| v7 方向正确率按 \|y\| 分层 | q1 0.37 → q5 0.585 | **大波动样本 v7 最准** |
| cos 内积 top20% 样本占比 | **74.4%** (extreme 5% 占 56.5%) | 未中心化 cos 被大波动样本主导 |

**机制闭合**: market 识别大波动 (AUC 0.78) × v7 在大波动最准 (0.585) × cos 只看大波动 (74%) → **幅度调制 pred' = v7 × (m/median)^γ 是零成本变现路径** (P5-02M, plan v1.8.0 S 级, 30 分钟, 待拍板)。

### 11.3 失败原因的五类归因

4. **量级不足**: E01/P6R/M 系列 — 信号真实 (全正) 但 < 门禁量级, 无法变现。→ 对策: 预注册门槛防止噪声入队。
5. **工程事故**: N007/P100/streaming panic — 远程环境差异。→ 对策: 幂等保护、日志、回归测试。

## 12. 成功路径归因 (为什么有效)

| 成功项 | 原理 | 通用性 |
|---|---|---|
| 融合 > 单模型 (blend 每 fold 全胜) | 模型/特征源多样性吸收不同归纳偏置 | 通用 |
| R2 归一化 (LB +0.001) | 无量纲表示对市场状态演化不敏感 | **漂移类比赛最通用杠杆** |
| 22 微观特征 (LB +0.002) | 事件结构相对量, 与窗口统计互补 | 微观结构类比赛 |
| RealMLP 152 特征 (LB +0.010) | **换特征源 > 换模型**: 事件动力学与窗口统计正交 | 通用 (公开强解复刻) |
| 外部 lb142 融合 (LB +0.007) | corr 0.82 → 18% 独立信息, 成品预测直接融合 | 通用 (作者开源时) |
| P5-01/P5-02I 信息审计 | 分源隔离 + surrogate 破坏 = 定位信息形态再选架构 | **研究纪律通用** |
| 严格时序 OOF + 预注册门禁 | 防止验证乐观偏差和噪声入队 | 通用 |

**元规律**: 三次突破全部来自"信息源/表示"变化, 而不是模型调参或 loss 微调。调参/loss 的收益上限 ≈ +0.001 (cosine 收口), 换信息源的单步收益 ≈ +0.002~+0.010。

## 14. 沉淀的纪律 (科研/工程)

1. **验证命题 ≠ 提交命题**: OOF 验证的配方/区间/α 选择必须与生产完全一致 (4.14 教训)。
2. **评估协议公平性**: NN 必须 best-state; loss 权重必须审计 (lambda_cos=0.01 事故)。
3. **提交三重门禁**: PSEUDO 稳定 + test 分布/尺度正常 (std 比) + 相关结构不坍缩。
4. **预注册协议**: 候选/门禁先写死再跑 (P6R 32/32 全正仍 KILL 的底气)。
5. **分 regime 校准**: 表格/新表示/外部预测三类分开, 不共用一个 LB≈PSEUDO 公式。
6. **双轴特征筛选**: Alpha 轴 (Δcos) × Drift 轴 (ΔAUC) 同时测。
7. **负面结果库制度化**: N001-N007 + 路线级失败全部记录, 防止重复踩坑。
8. **工程**: 幂等 resume / 产物哈希 / 回归测试 / 监控脚本自检。
