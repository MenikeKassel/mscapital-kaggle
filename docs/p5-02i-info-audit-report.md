## 2. 信息结构判读 (五条实锤)

1. **时序必要**: shuffle 崩 73-83% → 信息依赖时间顺序。✅ GPT 预言
2. **无时间箭头**: reverse 几乎不掉 (R=0.01) → 模型学的不是因果方向/趋势。时间反演对称结构。
3. **短程依赖**: block10 就崩 69-81%, block50 与 block10 无差别 → **有效信息尺度 ≤ 10 步 (30s)**, 无长程依赖 (>50 步信息 ≈ 0)。GPT 预期 "block50 崩 = 长程" 半对: 崩得最早的是 block10, 长感受野无必要。
4. **跨通道同步是核心**: desync 崩 77-94% (frozen Δ 仅剩 6%) → 信息主要在通道间**同时变化**的模式 (bid/ask/价格/成交联动的相对时序), 单通道自结构仅 ~20% 信息。✅ GPT 预言 (channel synergy)
5. **相位/非线性形态**: phase 崩 96%, Δ 转负 → 信息在事件形态/相位结构, 不在功率谱 (振幅/频率含量无信息)。

**一句话**: alpha = **短时窗 (≤30s) 内跨通道同步的、与时间方向无关的非线性事件形态**。

| probe | 指标 | 41-50 | 51-70 | 判读 |

### ⚠️ GPT1 猜想反转 (重要)

GPT1 预测 "I(X_m; sign) 较大 / I(X_m; |y|) 很小"。实测**完全相反**: 幅度 corr 0.43-0.47 (extreme AUC 0.78), 方向仅 0.56 AUC。**market 600s 告诉我们的主要是"接下来波动大不大", 而不是"涨还是跌"**。

**这同时给出 MSE 失败 / cosine 成功的精确机制**: y = sign·|y|, E[sign|x] ≈ 0 (AUC 0.56 微弱) → MSE 最优解 pred = E[y|x] ≈ 0 → corr(pred,y) ≈ 0 (P5-01 实测 −0.0013); cosine 只约束方向, 兑现那 0.56 AUC 的弱信号 → corr 0.086。幅度富矿 (0.43) 在两种目标下都被浪费 — 因为幅度必须乘上不可学的符号。

**建模含义**: 乘法双头 pred = sign_head(x) × mag_head(x) 理论上有独立增益空间 (方向头保 0.086, 幅度头 0.43 在 cos 指标中通过 |pred|∝|y| 加权贡献); 更直接: market 幅度预测 = **gating 信号** (何时 v7 弱/何时大波动), 支持 P5-05 gated alpha 设计。

### P5-03 预判 (负结果)

resid probe AUC 0.51 ≈ 0.5 → **market 对 y−β·v7 的方向无信息**。P5-03 序列版残差大概率死 (浅头诊断层面), 建议降级为可选验证, 不占用 S 级算力。

## 4. 架构结论 (信息结构 → backbone)

| 信息特征 | 架构要求 | 淘汰/确认 |
|---|---|---|
| 短程 ≤10 步 | 感受野 ~20-30 步足够, **无需长序列/长注意力** | 淘汰 TLOB/Transformer 时间注意力、长 TCN、PatchTST 类 |
| 跨通道同步核心 | **channel-mixing 第一优先** (per-step MLP / SE / 2D conv) | MLPLOB 首层 (逐时间步 FC) 结构天然匹配 |
| 无时间箭头 | 双向/无向均可, 方向性 RNN/SSM 无优势 | GRU/LSTM 不优先 |
| 非线性相位形态 | 非线性交互层 (MLP) > 线性统计 | 特征工程抓不住, 学到的表示优先 |

**backbone 建议 (P5-02)**: 短窗 (60-100 步) × 18 通道 → **Conv1D 短核 (k=3-5) × 2-3 层 + 显式 channel-mixing MLP 层** (MLPLOB-lite 风格), 或 MLPLOB 原版 (逐时间步 18→64 FC + 短时窗)。先做轻量对照: M0 架构 + 一层 per-step channel-MLP, 同协议看 frozen Δ 是否 > 0.0009。
