## 5. Q1–Q11 回答

**Q1. E02 的 context→residual 信号能否变成预测增量？**
**不能（在检索均值形式下）**。E02 的 HistGB residual cosine 0.013（窗口内非线性拟合）转换为严格 OOF 检索均值后，仅产生 +0.0002~+0.0006 增量，α 选择几乎全部卡在网格下界 0.05。E02 信号主要是"窗口内可解释性"，不是"跨月可迁移的预测增量"。

**Q2. 相似市场状态下 residual 是否具有局部可预测性？**
**弱存在**。corr(r̂,r) = +0.004~+0.010（32/32 正），K 单调增强，但月级 bootstrap CI 下界 ≤ 0（PSEUDO）——可预测性在月度层面不稳定。

**Q3. Local Ridge 是否优于 Global Ridge？**
**未测试**（P6R-01 未启动——P6R-00 门禁失败）。注: P6R-00 的 r̂ 等价于"常数特征"的局部模型；其信号已弱至 α 卡下界，P6R-01 的 X 特征加权回归能放大该信号的概率低（corr(r̂,y) 0.003–0.014 的残差可预测性远低于 0.0015 gate 所需）。

**Q4–Q6. Conditional Alpha / sign reversal / 跨月稳定？**
**无证据**（P6R-01 未执行，无从回答——按决策树不强行回答）。

**Q7. Market 32d latent 是否改善 retrieval？**
**未测试**（P6R-04 依赖前置 gate）。注: 按 P5-01 证据（corr(market,y)=0.086 序列形式），latent 可能比 E02 context 强，但决策树禁止跳过门禁直接启动。

**Q8. OOD support score 能否识别"不该修正"样本？**
**有间接证据**：worst month m66 的 −0.0030 回撤与远端月份/低 support 相关（support p50=0.69 意味着大量样本支持中等）；但未做正式 gate 测试（P6R-03 未启动）。

**Q9. support-gated correction 是否优于 ungated？**
**未测试**。

**Q10. 是否达到 +0.0015 PSEUDO gate？**
**否**。最大 +0.000588（PSEUDO cosine_K512），为 gate 的 39%。

**Q11. 下一步唯一推荐？**
**KILL retrieval prediction route（P6R-00→P6R-01 链）**。理由见 §7。备选（需用户显式拍板）: 仅 P6R-01 作为 H2 的最终裁决实验（低成本 ~1.5h），但因 P6R-00 已显示残差信号量级不足，期望值低；market latent 路线（P6R-04）在决策树上仍被门禁挡住。

## 6. Failure Analysis（任务书 §7 七项）

| 项 | 判定 | 证据 |
|---|---|---|
| Hypothesis false? | **部分成立** | residual 局部可预测性存在（corr>0, 32/32 正）但量级不足以变现（Δ ≤ +0.0006） |
| State representation wrong? | **可能（主嫌疑）** | E02 context 的窗口内解释力（0.013）≠ 跨月迁移力；P5-01 证明 market 序列信息强于聚合 context（corr 0.086 vs 0.014）——状态表示缺序列结构 |
| Retrieval metric wrong? | **否** | K 单调上升、邻居熵健康、corr(r̂,y0)≈0 正交——检索机制工作正常 |
| Residual target wrong? | **否（弱）** | β≈0.0004 使 r≈y 标度，但 β=1 变体对照将确认；E02 同一定义 |
| OOD drift? | **部分** | worst month m66 回撤 −0.0030；T4（最远期）信号最弱 (corr 0.0037) |
| Leakage? | **否** | 全部测试通过（28/28），严格时序断言 |
| Alpha selection overfit? | **否（反向）** | α 卡在网格下界 = 选择器认为修正价值极低，非过拟合 |

**根本解释**: E02 的 HistGB 在窗口内（同月训练+预测）看到 0.013 的 residual cosine，但该结构在"跨月迁移 + 检索均值"后被稀释到 corr ~0.005–0.010。残差 = y − β·y0 中，可检索迁移的部分 < 1%，其余是样本级噪声。这与既有证据链完全一致: P4-06A (+0.0000)、P5-02I resid probe (AUC 0.51)、P5-03 预判死、P6-01 降级——**P6R-00 是这条链的第四个独立确认**，且这次用的是 E02 已验证特征 + 最严格 OOF 检索。

## 8. 唯一推荐与后续选项

**唯一推荐: KILL P6R retrieval prediction route**（不启动 P6R-01/02/03/04/05；P6R-06 FiLM / P6R-07 MoE 的"state→residual 有预测力"前置条件不成立，自动取消）。

理由:
1. 预注册门禁失败（2/5 条件不满足，且是核心条件）
2. 量级差距大: 最大 Δ +0.000588 vs gate +0.0015（差 2.5×）
3. α 卡网格下界 = 修正价值远低于生产噪声
4. 与四条独立负面证据链一致（P4-06A / P5-02I probe / P5-03 / P6-01 降级），P6R-00 为第五个
5. E02 的 gate 通过信号（residual cosine 0.013）被证明**不可变现**——这本身是本轮最重要的科学产出: "残差可解释性 ≠ 残差可预测增量"

**可选（需用户显式拍板，不自动执行）**:
- **P6R-01 终裁实验**（~1.5h）: 若用户想彻底关闭 Conditional Alpha 问题——Local Ridge vs Global Ridge 是 H2 的直接检验，P6R-00 未能覆盖特征加权形态。期望值低（P6R-00 残差信号太弱），但科学上闭合。
- **P6R-04 单臂 market latent**（重训 P5-01 encoder，~4-6h）: 若用户认为状态表示是主嫌疑（failure analysis 第 2 项），latent 是唯一有正面证据的表示（P5-01 corr(y)=0.086）。但注意 P5-01 本身 frozen Δ 也只有 +0.0009——即使 latent 检索成功，增量上限仍可能 < +0.0015。
- 资源转向: P5-02M 幅度调制（plan v1.8.0 S 级，30 min，D1-D3 诊断支持）或 B-lite v2 跨源审计。
