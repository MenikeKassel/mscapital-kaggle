# 试过的方法（大白话版）

- 先做了表格树模型、R2 漂移归一化、22 个微观 primitive 和多模型融合，形成 152+73Z 与 Clean Baseline 两个冻结资产。
- RealMLP 在严格时序协议下成立；TCN、无监督 latent、幅度门、残差检索和 M01–M05 没有达到稳定晋级线。
- SCFI/Z 是当前唯一被生产吸收的条件创新；Cancel 与 Z 重叠，因此被吸收而不是叠加。
- E01 ReVol-lite 四折为正但 PSEUDO 不够；E02/E03 是诊断，不是预测模型。
- M06 没有可复现的 train/test 资产时间键，正式冻结为不可识别。
- 外部 lb142 与纯原创 P6-ORIG 分栏记录，不混入本地训练。

具体数值和证据索引见 registry 与项目状态报告。
