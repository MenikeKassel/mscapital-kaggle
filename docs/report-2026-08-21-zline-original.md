## 3. 为什么 idea 不起作用 (根因分析)

### 3.1 今天的 idea 本身没错 — 本地证据充分
- Z 线在纯原创锚上 blendΔ **+0.0062**, 是 v8b 锚 (+0.0014) 的 4 倍, 双测试窗口稳定;
- RealMLP-C(152+73Z) 优于 RealMLP(152) (同窗差 +0.0002~+0.0003);
- 纯原创候选 0.132 仍是**无 lb142 路线的最高分** (超 v5 0.125)。

**所以"Z 信息存在且互补"是成立的。问题不在信息, 在信息到 LB 的通道。**

### 3.2 根因一: CV-LB 校准缺口 ~0.01 (系统性)
MSCapital 反复出现: PSEUDO (eval 33-70, 回放已有月份) 与 test (全新未来月份) 有 ~0.01-0.02 的分布漂移差。
- v5: PSEUDO 0.1349 → LB 0.125 (gap 0.010)
- v7: PSEUDO 0.1397 → LB 0.135 (gap 0.005)
- 纯原创候选: PSEUDO ~0.141 → LB 0.132 (gap 0.009)
→ 本地 +0.0062 在乘以 ~0.5-1.0 的兑现率后, 净增量趋近于 0。**本地只能做相对排序, 不能预测绝对 LB 增益。**

### 3.3 根因二: lb142 是"已适配 test"的预测, 本地复现不出它的价值
- lb142 的价值 (+0.010: 0.132 → 0.142) 来自作者团队直接在 test 上推理, 含大量 test 侧工程/集成/校准;
- 这是**外生增益**, 本地任何切分都测不到 (我们的 PSEUDO 是回放, 不是 test 未来);
- 所以"去 lb142"天然要付出 ~0.01 的分数代价, 这是数据分布的事实, 不是我们做错了。

### 3.4 根因三: RealMLP 族内重叠 (仅解释 0.142 → 0.141)
- v8b 已含 RealMLP + lb142 的 RealMLP v9/v10, 再叠 RealMLP-C 是同族近亲;
- 本地 blendΔ +0.0014 真实互补, 但 LB 侧增量被压缩并翻转 (-0.001);
- 结论: v8b 之上继续叠 RealMLP 系 = 边际饱和, 不重复。

## 4. 方法论含义 (今天的资产)

1. **本地 PSEUDO 的价值 = 原创内部相对排序**, 不是绝对 LB 预测器; 诚实标注每次 CV-LB 兑现率。
2. **原创路线的独立能力基准 = 0.132**, 干净、可复现、无外部污染, 作为后续所有原创组件叠加的新锚。
3. **突破原创 0.132 需要的新东西** (不是再叠同族):
   - a) 真正新的信息源 / 残差增量 (> 现有 152+Z);
   - b) 对分布漂移鲁棒的表示 (而非更多特征);
   - c) 若追求榜分: 接受外部融合 (lb142 等) 合法且最高效, 与原创线并存。
4. **今日验证的 Z 线归因**结论稳固: 撤单族 ⊂ Z, 152+73Z 是原创线上最强的特征集。
