## 5. 关键校准与判断

1. **CV-LB 漂移差 ≈ 0.017** (CV1 0.139 → LB 0.122): 测试期 (m71-108) 是分布外, 与社区观察一致 (Transformer CV 0.155 / LB 0.120)
2. **表格融合路线已饱和**: v1→v2 CV +0.0004 未转化为 LB 提升 → 表格特征+树+MLP 组合在 LB 0.122 封顶
3. **负面结果库**: 时间加权无效; >90特征过拟合; 自定义cos loss破坏CV-LB相关 (社区); 增强窗口特征无收益
4. **文献支持** (20篇已核验): OFI 有强实证 (Cont 2014); "输入表示>模型结构" (HLOB); 分布漂移应对 (AdaRNN); 表格+漂移增量学习 (2303.07925)
